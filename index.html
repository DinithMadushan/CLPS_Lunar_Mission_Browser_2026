About & data policy

Mission facts come from NASA and provider documentation; each record keeps its source URL and last-checked date. Unknown values are shown as unknown, never filled in.

Simulated: surface terrain (procedural, not real topography), the lander model (generic), the astronaut (scale reference only), Earth texture (stylised), environment effects in Mode B.

Solar System layout uses a compressed visualisation scale — not a physically accurate distance map.

Orbital globe model: models/moon.glb. Three.js (MIT) is bundled locally.
